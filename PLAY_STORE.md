# WarHex Google Play release checklist

## Architecture
- Web/Android UI: Next.js + React + Tailwind + Framer Motion.
- Real account authentication: existing WarHex backend at `NEXT_PUBLIC_API_BASE_URL`.
- Other players/rooms in the current UI are presentation/demo entities until a realtime game-room backend is connected.
- Android: Capacitor wrapper generated by GitHub Actions.

## Required secrets for a signed Play release
Create Android signing secrets in GitHub Actions and replace the debug-only release step with a keystore signing step. Never commit a keystore or passwords.

## Required production environment
- `NEXT_PUBLIC_API_BASE_URL=https://project-111111111.onrender.com`
- `CAPACITOR_SERVER_URL=https://project-111111111.onrender.com`

## Google Play
As of 31 Aug 2026, new apps and updates submitted to Google Play must target Android 16 / API 36 or higher. See official Android documentation.

## Important
A Play Store listing is not guaranteed merely by a successful build. You still need a signed AAB, privacy policy, Data safety declarations, content rating, app access information, screenshots, icon, and compliance with Play policies.
